# 诗云 · Poetry Cloud

> 一片包含**所有可能的五言绝句**的星云。每一首诗，都有它唯一、确定的位置——包括人类写过的每一首。
>
> 灵感来自刘慈欣短篇小说《诗云》。

**▶ 在线游玩：https://maxi-max-dev.github.io/poetry-cloud/**

## 它是什么

一首五绝 = 4 句 × 5 字 = 20 个汉字。字库取古典诗歌高频 3000 字，于是「所有可能的五言绝句」共有 3000²⁰ ≈ **10⁶⁹ 首**——比可观测宇宙的原子总数还多。

这个网页让你在这片星云中：

- 🛸 **自由飞行**，凑近任何一首诗阅读——绝大多数是字的无意义组合，正如原著的设定
- ✎ **寻诗传送**：输入任意 20 个字，直接跳到这首诗所在的位置
- 🪐 **看邻居**：身边的诗只和你差几个字——二、三、四句的末字随空间方向渐变；起句相同的诗聚在同一片星区
- ⭐ **认出人类的诗**：飞近《静夜思》《江雪》这类真实名作时，它会在乱诗之海中亮起金光

## 它怎么做到的

不可能存储 10⁶⁹ 首诗——但**不需要存**。每首诗和三维坐标之间是一个确定的双向映射：

- 20 个字按位置拆成三组，各组按混合进制（基数 = 字库大小 N）折叠成一个大整数，作为 x / y / z 坐标
- 低位字 = 各句末字 → 空间上相邻的诗只差句末几个字；首句五字全在最高位 → 同一起句的诗聚成星区
- 坐标范围达 N⁷ ≈ 10²⁴，用 BigInt 精确表示，渲染时以**浮动原点**保持相机附近的浮点精度
- 引擎只实时生成相机周围的几百首诗（近景为 canvas 文字卡，远景为光点云），飞到哪算到哪

纯前端单页应用，Three.js 渲染，无后端、无构建步骤。

## 本地运行

下载 `index.html` 和 `data.js` 放在同一目录，双击 `index.html` 即可（首次需联网加载 Three.js）。
